# Fuqua ConCert

A course planner for the Duke Fuqua full-time MBA. Enter the courses you have taken and plan to take across the eight quarters of the program, and see which concentrations and certificates they apply to, laid out as a skill map.

Unofficial. This is a planning aid, not a degree audit. The Fuqua registrar is the authority on what you have earned.

Status: governance and design complete, no application code yet.

The repository is `FuquaConAndCert`; the tool is called Fuqua ConCert. The names differ for historical reasons.

## For contributors
